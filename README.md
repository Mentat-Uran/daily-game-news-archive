# Daily Game News Archive

每日单机游戏资讯的长期 Markdown 归档仓库。

## 覆盖范围

- PC
- PlayStation（PS5 / PS4）
- Nintendo Switch 2
- 每日 Xbox Game Pass / PC Game Pass / Game Pass Ultimate 新增追踪
- 单机或买断制游戏的新作、发售、延期、DLC、重要补丁、评测与口碑、国产单机、厂商与平台动态

## 目录结构

```text
reports/
└── YYYY/
    └── MM/
        └── YYYY-MM-DD.md
```

完整日期索引见 [`index.md`](index.md)。

## 自动归档

日报由 ChatGPT 定时任务生成。每次任务完成后，除聊天输出与邮件发送外，还会尝试把完整 Markdown 日报归档到本仓库，并同步维护日期索引。

## 历史迁移说明

仓库初始化时已尽可能从此前实际发送的“每日单机游戏资讯”邮件和当前可恢复的聊天日报中迁移历史记录。历史文件保存的是当时生成/发送的日报快照；迁移过程不会重新核验每一条旧新闻，因此旧文件不应被理解为在迁移日期重新确认过的事实。

同一日期若存在多个版本，优先采用内容更完整的版本，并在必要时合并多个已发送版本中的独有条目。没有可恢复完整日报的日期不会凭空补写。
